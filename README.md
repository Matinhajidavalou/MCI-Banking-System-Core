# MCI BANKING SYSTEM CORE

این پروژه یک شبیه‌ساز از یک سیستم بانکی است که در زبان پایتون توسعه یافته است. این سیستم قابلیت اجرای توزیع‌شده در بستر شبکه را دارا می‌باشد.

---

## ✨ ویژگی‌های کلیدی

- **معماری توزیع‌شده:** استفاده از `Socket Programming` روی پروتکل TCP برای برقراری ارتباط پایدار بین هسته مرکزی و دستگاه‌های عابربانک.
- **داشبورد گرافیکی زنده (Real-time GUI):** پنل مدیریت واکنش‌گرا با `customtkinter` که بدون فریز شدنِ برنامه، تغییرات شبکه را لحظه‌ای نمایش می‌دهد.
- **الگوهای طراحی (Design Patterns):** 
  - **Singleton**
  - **Observer** 
- **(Concurrency)**
- **تبادل امن داده‌ها:** رمزنگاری و ارسال Payload در بستر شبکه با فرمت استاندارد `JSON`.

---

## 📂 فایل‌های پروژه


| نام فایل | وظیفه و نقش|
| :--- | :--- |
| `bank.py` | هسته اصلی بانک و منطق مدیریت حساب‌ها و مشتریان |
| `models.py` | موجودیت‌های اصلی (کلاس‌های حساب، مشتری و تراکنش) |
| `exceptions.py` | مدیریت خطاهای اختصاصی سیستم مالی |
| `observer.py` | پیاده‌سازی الگوی طراحی آبزرور برای سیستم لاگینگ |
| `server.py` | نقطه ورود سرور مرکزی و مدیریت Threadهای شبکه |
| `atm.py` | برنامه کلاینت عابربانک برای اتصال به سرور مرکزی |
| `gui.py` | داشبورد مدیریت سیستم بانکی مبتنی بر CustomTkinter |

---

## 🚀 راهنمای نصب و راه‌اندازی

### ۱. نصب پیش‌نیازها
برای اجرای رابط گرافیکی به کتابخانه `customtkinter` نیاز دارید. دستور زیر را در ترمینال اجرا کنید:

```bash
pip install customtkinter
```

### ۲. ترتیب اجرای سیستم
> **⚠️ نکته حیاتی:** برای عملکرد صحیح معماری شبکه، فایل‌ها باید **دقیقاً به ترتیب زیر** در ترمینال‌های مجزا اجرا شوند.

**گام اول:** روشن کردن هسته مرکزی (سرور در حالت Listen روی پورت ۵۰۵۰ قرار می‌گیرد)
```bash
python server.py
```

**گام دوم:** اجرای داشبورد مدیریت (برای ثبت مشتری و افتتاح حساب)
```bash
python gui.py
```

**گام سوم:** اجرای کلاینت عابربانک (ATM)
```bash
python atm.py
```
